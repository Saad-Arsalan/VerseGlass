# Security

Please [report vulnerabilities privately](https://github.com/Saad-Arsalan/VerseGlass/security/advisories/new). Include the affected release, macOS version, impact, and enough detail for the maintainer to investigate. Remove access tokens, private listening history, and unrelated device details from logs.

Security fixes ship in the current [stable release](https://github.com/Saad-Arsalan/VerseGlass/releases/latest). For ordinary playback and installation problems, use the [bug tracker](https://github.com/Saad-Arsalan/VerseGlass/issues/new/choose).
