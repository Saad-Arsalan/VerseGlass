# Contributing to VerseGlass

Use [Issues](https://github.com/Saad-Arsalan/VerseGlass/issues/new/choose) for reproducible bugs and feature requests. Use [Discussions](https://github.com/Saad-Arsalan/VerseGlass/discussions) for setup questions and early ideas.

1. Fork the repository and create a branch from `main`.
2. On a Mac with the Xcode Command Line Tools, run `./build.sh`. Open `build/Verseglass.app` and exercise the feature you changed.
3. Open a pull request describing the change, your macOS version, and what you tested. For lyric changes, use an original sample when sharing screenshots or test data.

The maintainer groups accepted changes into [numbered releases](CHANGELOG.md). The [release instructions](AGENTS.md) describe how to ship one.
